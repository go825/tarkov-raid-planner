# Public launch checklist

- [ ] リポジトリ所有者が一般公開を明示承認した。
- [ ] Lint、全自動テスト、production build、データ監査が成功した。
- [ ] モバイル／デスクトップでOverview、My Tasks、Raid plan、Party、Settingsを確認した。
- [ ] 未認証／認証済みの保存、共有、参加、競合解決を確認した。
- [ ] データエクスポートと削除をテスト用アカウントで確認した。
- [ ] Privacy、Terms、Credits、免責表示を確認した。
- [ ] Security headers、API rate limit、404／エラー表示を確認した。
- [ ] D1 migration、Secrets、tarkov.devフォールバックを確認した。
- [ ] 障害対応責任者とロールバック対象版を記録した。
- [ ] 公開設定を変更し、匿名ブラウザで到達性を確認した。
- [ ] 公開URLとデプロイ版をworklogへ記録した。
